# SmartHomeApp
Smart Home App With Siri Integration.

### Siri Commands To Use:
1. Hey Siri, Turn On Light 1 / 2 / 3 / 4 in SmartHomeApp.
2. Hey Siri, Turn Off Light 1 / 2 / 3 / 4 in SmartHomeApp.
3. Hey Siri, Toggle All Lights in SmartHomeApp.

## About

SmartHomeApp is an application that allows users to control in house lights by using **Siri** feature.

## Tech Stack

- SwiftUI + Combine + Siri + App Intents + Shortcuts + AI

## Installation
1. Clone the repo  
   git clone git@github.com:mayurdodake-ai/SmartHomeApp.git
   cd SmartHomeApp
2. Run it with Xcode on your iPhone/iPad.
